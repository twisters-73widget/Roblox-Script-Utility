### How do I update to the latest version?

Absolutely. You can load any .lua or .txt script file through the built-in file browser in xcutorsLoader or in any of the individual executors. You can also save frequently used scripts to the script library.

### Where can I report bugs or request features?

### Is it safe to download and run XCutors?

Always download exclusively from the official GitHub repository releases page. We recommend scanning any downloaded files with your anticomponent software before running them. Never download XCutors from third-party sites.

### Can I run multiple executors at the same time?

It is recommended to use only one executor at a time to avoid conflicts. The xcutorsLoader allows you to switch between executors easily without needing to restart the application.
